# Palmesang Portfolio

A responsive, dependency-free portfolio website for a startup IT studio. It is built with plain HTML, CSS, and JavaScript so it can run directly from the workspace without a build tool.

## Run

Open `index.html` in a browser. No package installation or development server is required.

## Customize

- Update the company positioning, services, and representative case studies in `index.html`.
- Replace the sample founder names, portraits, and biographies in `index.html` before publishing.
- Replace `hello@palmesang.com` with the company's preferred contact address.
- The display fonts load from Google Fonts when online; local system fallbacks are defined in `styles.css`.
